# Переработка проверки синонимов и упражнений на различия

Заменяет реализацию из [старого плана](../plans/2026-09-14-001-feat-fair-synonym-practice-plan.md).
Причины переработки: [глубокое ревью локальных изменений](2026-09-15-local-changes-deep-review.md).

## Как устроено обучение

1. Обычная тренировка принимает подходящий синоним и объясняет различие.
   Корректность ответа и запоминание изучаемого слова учитываются отдельно.
   Синоним засчитывается в результате сессии, но не меняет интервал карточки.
2. После альтернативного ответа на изучаемом языке доступны «Дальше» и
   «Различия · 3 задания». Для сравнения выделяется короткое выражение из ответа;
   полное предложение ученика не становится автоматически вторым членом пары.
3. Отдельную тренировку также запускает `/contrast verfügbar / zugänglich`.
   Первое выражение должно быть активной карточкой ученика. Новая сессия заменяет
   текущую: сначала короткое объяснение с примерами, затем три ситуации с выбором
   «только первое», «только второе» или «оба подходят». После ответа видны ключ,
   объяснение и полная фраза-пример. Интервалы слов не меняются.
4. После синонима карточка исключается из оставшейся обычной сессии. При следующем
   повторении предпочтение получает контекст с пропуском. Успешное воспроизведение
   снимает это предпочтение и возвращает обычный подбор заданий по стадии.

Различия пока повторяются по инициативе ученика, через кнопку или команду.
Отдельного расписания повторений пар нет. Три задания не обязаны содержать
по одному ключу каждого типа: допустимость двух выражений важнее симметричного набора.

## Архитектура

- `vocab/grading.py`: единая политика правильности, оценки сессии и изменения SRS.
  Модель не управляет интервалами и не выбирает числовую оценку повторения.
- `bot/grader.py`: смысловая проверка несовпадений, включая обычные кнопочные ответы.
  В API передаются видимое условие и ответ. Карточка, её скрытый пример и эталон
  остаются во внутреннем снимке задания. Изучаемое выражение передаётся отдельно
  для определения факта воспроизведения и объяснения отличия.
- `bot/context.py`: генератор составляет ситуацию; независимый вызов оценивает
  применимость каждого выражения и формирует ключ, объяснение и пример. Он не
  видит предложенного эталона генератора. Неуверенность, невалидное условие или
  отсутствие подходящих вариантов вызывают одну повторную генерацию; после
  второго отказа упражнение не сохраняется.
- `vocab/context.py`: различия используют существующую контекстную сессию,
  `objective=contrast`, `target_count=3` и проверку кнопок по подготовленному ключу.
  Пара хранится в `sessions.comparison`, а не внутри карточек и CSV.
- Скрытые обязательные слова убраны из свободной контекстной практики.
  В заданиях на применение нужная фраза прямо показана в условии.
- Многоступенчатые подсказки и цепочки повторных попыток заменены действием
  «Показать ответ и пропустить». Пропуск и сбой проверки не создают отрицательный
  review. Старая помощь учитывается при чтении истории существующей сессии.

Сохранены независимые улучшения исходного изменения: пропуск всей фразы,
выбор смыслового глагола при построении cloze, очистка запросов YouGlish
и разбиение длинной справки на сообщения Telegram.

## Проверки

Полный набор: `.venv/bin/python -m unittest discover -s tests` — **123 теста прошли**
(включая исправления по пользовательскому скриншоту).
`ruff check` для изменённых Python-файлов и `git diff --check` также прошли.
Отдельные интеграционные сценарии находятся в `tests/test_synonyms.py`:

- правильный синоним → вердикт → счётчики → следующее повторение в контексте;
- обе стороны обычного выбора и реальный обработчик кнопочного ответа;
- отличие неверного ответа от невалидного задания и пропуска;
- повторное нажатие, гонка пропуска с проверкой, защита следующего задания;
- запоздавшая ошибка генерации не останавливает новую сессию;
- три упражнения на различия, независимый ключ, объяснение и пример;
- отказ проверки, повторный запуск после сбоя, изоляция учеников;
- отсутствие скрытой карточки в данных смысловой проверки;
- переход с заполненной схемы 014 на 016 без потери старых счётчиков.

Дополнительно выполнены реальные вызовы настроенной `gpt-5.6-luna` только на
синтетических данных во временных БД. Пробы выявили две проблемы: согласование
проверки с предложенным ключом и влияние скрытого примера карточки на оценку
широкого перевода. Итоговый код устраняет оба источника влияния.

В финальной пробе отдельная сессия завершила все три задания; ключи были
«только zugänglich», «оба», «оба». После изменения данных grader три независимых
повтора `доступный → verfügbar` получили `accepted`, `target_reproduced=false`.
Явно неподходящее `Apfel` в пропуске получило `rejected`. Это ограниченная проверка
качества модели; она не гарантирует безошибочности языковых объяснений для всех пар.

### Исправления по скриншоту карточки

Убраны повторяющиеся строки «Ваш ответ / Слово / Ещё один вариант». Результат
оформлен HTML: короткий заголовок, одна строка ответа или исправления, перевод,
пояснение отдельным абзацем и пример в цитате. Динамический текст экранируется.

Опечатка `gründsätzlich → grundsätzlich` больше не обозначается подходящим
синонимом. Для частичного ответа grader возвращает исправленный вариант;
если локальная проверка узнаёт в нём цель задания, это попытка воспроизведения
изучаемого слова с качеством 3. Вердикт сохраняет исходное решение `partial`,
поэтому заголовок «Почти правильно» не зависит от нейтральности упражнения.
Исправление опечатки в другом синониме по-прежнему не увеличивает прогресс цели.

Интеграционные тесты проверяют полный путь до HTML-сообщения и отсутствие
предложения сравнивать слово с его опечаткой. Реальная модель проверена на
синтетических `gründsätzlich` и `verfügbar`; оба сценария дали ожидаемые решения.
Для исправления одной буквы пояснение строится непосредственно по разнице
ответов, чтобы не показывать выдуманные моделью дополнительные ошибки.
После этой правки повторно прошли 44 теста оценки и Telegram-потока.
Обновление загружено штатным перезапуском рабочего бота без миграций;
новый процесс начал Telegram polling без ошибок.
